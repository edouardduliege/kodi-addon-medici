Medici.tv for Kodi

Unofficial Kodi addon for Medici.tv.

Features
- Browse concerts, operas, ballets, documentaries, master classes and jazz
- Favorites
- Search
- Audio-only playback
- Audio + video playback
- Selectable video quality up to 1080p
- Medici.tv account authentication

Requirements
- Active Medici.tv subscription
- Kodi 21+

This addon is unofficial and is not affiliated with Medici.tv.
